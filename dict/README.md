These are the dictionaries OpenCC 1.4.2's `s2twp.json` uses, extracted as text from
the official build (the `opencc` 1.4.2 wheel) with its own `opencc_dict` tool, so they
include `STPhrases_GeneratedFromRegionalPhrases`, which OpenCC generates at build time.
